# WorkMint Select

仕事道具、学び、業務サービス、仕事環境について、選ぶ前に調べた過程と根拠を残す個人メディアです。

## 公開URL

https://workmint-tools.github.io/workmint-select/

## 運営者

WorkMint（筆名）。外資系IT企業で働く40代のワーキングマザー。子育てと両立できる副業を模索しながら、時間・年間費用・運用の手間を基準に調査します。

## 現在の特集

事業用住所とバーチャルオフィス。今後はデスク環境、ソフトウェア、オンライン学習、日々の仕事の整え方も扱います。

## 方針

- 特定ジャンルの量産比較サイトにしない
- 実際に選ぶ場面が来たテーマから調べる
- 公式情報・一次情報を優先する
- 未経験の商品について利用者を装わない
- 広告掲載を明示する
